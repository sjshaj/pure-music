# 纯音 (Pure Music)

专为**红米 Note 4（高通 625 + 第三方 AOSP 15 无 GMS）**量身打造的极简离线单手音乐播放器。

遵循 **“少即是多（Less is more）”** 的设计哲学：音乐优先，打开即播；默认离线；单手操作；按意图搜歌，彻底消灭繁琐的标签页与手动建歌单。

---

## 🌟 核心设计理念

1. **音乐优先（开屏即听）**
   - 启动直接进入主播放界面，自动恢复上次播放进度。
   - 无广告、无开屏等待、无社交广场。
2. **极致省电（高通 625 硬件直解）**
   - 启用 **AndroidX Media3 硬件音频卸载（Audio Offload）**。
   - 音频数据直接交付芯片 Hexagon 546 DSP 处理，熄屏播放时 8 核 Cortex-A53 全部深度休眠。
   - 设置 20~60 秒超大音频缓冲区，最小化 CPU 唤醒频率。
3. **极简流畅（无 GPU 负担）**
   - 彻底废除实时毛玻璃高斯模糊（防止老旧 Adreno 506 GPU 掉帧发热）。
   - 纯粹的深色模式与原生大黑胶圆盘，满帧丝滑。
4. **单手极限操作**
   - 所有高频操作集中在下 1/3 拇指舒适区。
   - 左右滑切歌、双击收藏红心。
5. **按意图找歌（零费力整理）**
   - **消灭标签页（No Tabs）**。
   - 自动提取本地存储文件夹作为天然合辑（如“欧美摇滚”、“车载轻音乐”）。
   - 智能识别“喜欢”、“常听”等意图标签，支持拼音模糊即输即播。
6. **绝不丢歌**
   - 音乐文件直读本地 `MediaStore`。
   - 播放偏好与红心收藏自动同步为本地极简 JSON 备份文件，换机永不丢失。

---

## 📱 适配与运行环境

- **推荐设备**：红米 Note 4 (mido) / 骁龙 625 及同类设备
- **系统版本**：Android 15 (API 35 独占架构)
- **GMS 状态**：零依赖，完全支持纯血脱敏 AOSP 系统
- **ABI 支持**：`arm64-v8a` 专机编译
- **安装包体积**：约 5.2 MB（经过 R8 极限混淆优化）

---

## 🛠️ 构建与编译

本项目使用 JDK 21 和 Gradle 构建：

```bash
# 编译 Debug 版
./gradlew assembleDebug

# 编译 Release 版（已包含 R8 极限精简与内置签名）
./gradlew assembleRelease
```

输出 APK 路径：`app/build/outputs/apk/release/app-release.apk`

---

## 📦 快速安装

可以直接下载项目根目录下的 `PureMusic_v1.0_sd625.apk`，或通过 Releases 页面下载安装包：

```bash
adb install PureMusic_v1.0_sd625.apk
```
